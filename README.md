# 🏦 Banking & Loan Risk Analytics

## 📊 Customer & Loan Default Risk Analysis

An end-to-end banking analytics project focused on understanding **loan default risk, customer characteristics, credit behaviour, financial indicators, and portfolio performance**.

The project uses the **Home Credit Default Risk dataset** and combines **Python, SQL/PostgreSQL, database design, and Power BI** to transform raw banking data into meaningful business insights.

---

# 📌 Project Overview

This project analyses loan application data to identify patterns associated with loan default risk.

The analysis covers:

- Loan applications
- Default and non-default customers
- Customer demographics
- Income levels
- Credit amounts
- Annuity amounts
- Employment duration
- Loan terms
- Education
- Housing type
- Occupation
- Family status
- Credit-to-income ratios
- Credit-to-goods-price ratios
- Previous credit history
- Repayment behaviour

The project follows an end-to-end analytics workflow:

**Raw Data → Data Understanding → Exploratory Analysis → Database Design → SQL Data Cleaning → SQL Business Analysis → Power BI Dashboard → Business Recommendations**

---

# 🎯 Project Objectives

The main objectives of this project are to:

- Understand the structure and quality of the banking dataset.
- Analyse loan applications and default behaviour.
- Calculate the overall default rate.
- Identify customer groups with different observed default rates.
- Analyse the relationship between financial characteristics and default risk.
- Analyse credit history and previous applications.
- Examine repayment behaviour.
- Perform data cleaning and validation using SQL.
- Design a structured PostgreSQL database.
- Create an interactive Power BI dashboard.
- Identify important business insights.
- Provide data-driven recommendations for further risk assessment.
