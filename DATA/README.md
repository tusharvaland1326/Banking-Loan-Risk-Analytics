# Data

This folder is reserved for the datasets used in the Banking Loan Risk Analytics project.

The project uses the Home Credit loan risk dataset, including:

- application_train.csv
- application_test.csv
- bureau.csv
- bureau_balance.csv
- credit_card_balance.csv
- installments_payments.csv
- POS_CASH_balance.csv
- previous_application.csv
- HomeCredit_description.csv

## Dataset Note

The original CSV files are not included in this GitHub repository because the datasets are large and exceed GitHub's standard web upload file-size limit.

The analysis notebooks, SQL scripts, Power BI dashboard, screenshots, and project report are included in the repository.

The datasets can be downloaded separately from the original dataset source and placed in this folder to reproduce the analysis.
