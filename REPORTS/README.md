# Reports

This folder contains the professional reports created for the Banking Loan Risk Analytics project.

The report will document:

- Project Overview
- Business Objectives
- Dataset Description
- Data Analysis Methodology
- Key Performance Indicators
- Key Findings
- Loan Risk Analysis
- Credit History Analysis
- Repayment Behaviour
- Power BI Dashboard
- Business Recommendations
- Skills Demonstrated
- Project Learning Outcomes
- Conclusion
- Author Information
